# 文档切分方式补充

参考用户提供的百炼截图及[官方切分说明](https://help.aliyun.com/en/model-studio/rag/chunking)，界面展示六种互斥切分方式，不把内容组织、检索上下文和算法细节重复计数。

| 方式 | 使用场景与行为 |
|---|---|
| 智能切分 | 先识别段落、标题、表格结构，再调用已配置 Embedding 按相邻段落语义相关性合并；支持调整阈值，产生真实向量调用用量。 |
| 按长度 | 以字符或通用 Token 数控制长度与重叠。 |
| 按页 | 使用 PDF/云端解析的真实页码，不混合页面；长页细分。无页码时明确提示。 |
| 按标题 | 支持 Markdown 标题和 Word 标题样式；按所选层级及更高级标题分章节，较低级标题保留在所属章节。 |
| 按正则 | 按正则匹配位置划分，设执行超时、数量上限和空匹配保护。 |
| 按符号 | 支持多个字面分隔符，包括空行、换行、分隔线、句号与自定义标记，无需编写正则。 |

正则、符号支持将分隔标记保留在前一片段结尾、后一片段开头，或移除。段落归入符号的空行预设。父子检索是独立开关，表示小片段召回后补充较大上下文；不等同按标题切分，父片段也遵守明确的页、章节及分隔符边界。问答对放在高级内容组织中，启用后不叠加普通文档切分。

最大长度为 10–6000，字符与 Token 可选。Token 使用随项目打包的 cl100k_base 词表，不下载模型权重；各服务商实际计费以服务商用量为准。词表来自 OpenAI tiktoken，SHA256 为 `223921b76ee99bde995b7ff738513eef100fb51d18c93597a113bcffe865b2a7`，附 MIT 许可。

智能切分支持表头拼装：开启时表头随行组重复，关闭时仅在首组保留。单个表格行或完整问答超长时保留完整内容，预览给出长度提示；要求严格长度时选择按长度。

兼容旧 structure / semantic / paragraph 参数；已有索引不会自动重建。用户确认新方案并构建后才切换索引。

验收入口：知识库 → 智能导入与加工 → 导入或选择文档 → 元数据确认 → 切分预览。选择卡片、生成真实预览、确认版本并构建。PDF 验证按页；带层级标题的 Word/Markdown 验证按标题；固定标记资料验证按符号/正则。
