# v1.2.6 真实可观测与案例回流

## 可观测中心

管理与监测 → 可观测中心展示当前角色授权范围内的真实对话、应用和知识任务。筛选、详情按需加载，普通状态轮询只返回摘要。点击“查看执行过程”，在同一页面展开节点输入/上下文、模型可见输出或工具结果、异常、用量及当前实现代码摘录和解释。报告显示已生成的大纲；模型未返回的内部推理不可获得，历史没有采集的字段标记未采集。

新发生的应用 Agent 执行记录逐轮模型输入消息、可见响应、工具调用、参数、输出、状态、耗时和服务商用量；Skill 激活与资源读取是工具节点。普通流式对话、知识检索、Embedding、Rerank、报告生成及知识任务解析/切分/索引阶段记录可获得的输入、输出与异常。向量数值没有记录，只显示数量和维度。工具/模型实际行为取决于配置和服务商。当前的逐节点代码是当前仓库实现摘录，不保证与历史部署完全一致。

模型密钥、常见授权字段和已知密钥样式会脱敏；单个字段超过 30000 字符标记截断，列表超过 100 项标记截断。历史日志可能只含摘要。真实 LLM 用量以供应商返回为准；OCR/重排计量格式可能不同。价格、实际账单未接入，费用显示未定价。统计基于当前状态接口已载入的数据：最多 1000 条日志、500 个知识任务和当前浏览器最近 100 个报告任务，不是全量账单。

## 评测集和线上案例回流

管理与监测 → 评测集可新建多个评测集。在可观测中心或对话日志的记录中点击“加入评测集”，选择 Good Case 或 Bad Case，可填写备注与期望答案。每条案例保存问题、回答、来源、模型、用量和状态快照，原日志过期后仍可查看；同一条日志可加入不同评测集，同一评测集不重复。支持筛选、修改标签/备注/期望答案、导出及移除案例。移除案例不删除原始日志。

案例由管理角色维护，知识库管理人员只可查看其可访问知识库的案例。当前免登录角色自由切换属于体验模式，不提供可验证的人员身份隔离。自动执行评测和自动评分不在本版范围。

## 验收

1. 在应用中心运行启用计算工具的应用，提问后打开可观测中心 → Agent 运行 → 查看执行过程；展开模型、工具节点，核对模型消息、工具参数/结果、状态与代码解释。
2. 查看知识库构建、对话日志与异常；旧记录中未保存的节点内容显示未采集。
3. 对一条真实日志点击“加入评测集”，创建评测集并标记 Good/Bad，填写备注及期望答案。
4. 进入“评测集”检查快照、筛选与修改；原日志到期不会删除已收集案例。用量与费用视图检查未知数据没有计为零。
