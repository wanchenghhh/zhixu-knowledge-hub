怎样验收这一版？

直接在云端完成导入、构建与真实知识问答。
元数据、版本检索与多场景应用已接入真实服务端。

查看完整验收说明 →
  1. 打开 Web 知识中台，切换管理员、知识库管理人员、使用者。
  2. 新建知识库，导入示例或本地 Markdown，查看解析预览。
  3. 确认版本并构建，在对话中查看当前与历史资料引用。
  4. 在应用中心发布客服或报告应用，查看任务、日志并导出报告。
  5. 图片、扫描 PDF 请先在解析设置配置云端 OCR。
