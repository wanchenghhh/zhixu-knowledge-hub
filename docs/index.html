怎样验收这一版？

先完成一轮 Web 体验，再按需运行真实后端。
此次发布按要求不新增测试。

查看完整验收说明 →
  1. 打开 Web 体验版，切换管理员、知识库管理人员、使用者。
  2. 新建知识库，导入示例或本地 Markdown，查看解析预览。
  3. 确认构建，在在线对话提问并查看引用来源。
  4. 检查任务、日志、模型配置入口，刷新确认本地记录保留。
  5. 真实云模型联调请使用本机 http://127.0.0.1:8000。
