# v1.2.4 可观测中心原型

本版本交付桌面 Web 交互原型。路由 `/observability`，侧栏入口“管理与监测 → 可观测中心”；知识库增加“观测构建 · 原型”，应用列表增加“观测运行 · 原型”。原 `/logs` 保留现有真实对话日志，中心右上角可以进入，日志页可返回中心。

六个视图：总览、知识库构建、Agent运行、对话日志、用量与费用、异常事件。固定示例日期2026-10-28；按状态、对象、关键词筛选，链接保留筛选状态，空结果及导出均可体验。总览与费用按当前筛选示例计算，未知用量不按零补齐。

点击查看链路，切换调用树/时间线，点击模型、工具、Skill节点，再查看输入输出、上下文、用量、事件、异常和元信息。调用树包含父子关系，时间线展示等待与执行位置。采集设置为方案预览，开关不保存到服务端。

所有示例来自独立前端fixtures，不读取、推测或混入生产调用与账单。Skill、Harness、调用树和估算费用尚未接入真实后端；真实日志继续使用现有权限和服务端接口。没有新增埋点数据库、云资源、模型调用或自动重放能力。

## 验收

1. 管理员或知识库管理人员打开 `/observability`，导航和面包屑正确；切换六个页签。
2. Agent运行选择“失败”，列表只保留失败示例；清空筛选后可看到等待确认。
3. 打开失败报告，选择导出工具，在“异常”查看参数校验错误；选择Skill查看“已加载”，选择章节LLM查看未知用量。
4. 用量与费用能下钻到叶子模型调用，未定价与实际账单未接入清晰展示；导出的JSON标明示例数据。
5. 右上角进入现有真实对话日志并返回；知识库、应用中心入口能进入对应原型视图。
6. 刷新带筛选的URL能恢复视图；使用者访问观测中心按现有页面权限返回在线对话。

详细功能设计见 [可观测中心功能设计](12-可观测中心功能设计.md)。
