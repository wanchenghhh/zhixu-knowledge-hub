# v1.1 云端真实 RAG

入口：https://zhixu-knowledge-hub-wan-cheng.vercel.app

## 验收流程

1. 切换管理员，在模型服务确认 AIHubMix 的 LLM、Embedding、Rerank 配置。
2. 新建知识库，选择向量与重排模型，并设置三个角色的可见范围。
3. 导入 Markdown、Word、文字型 PDF 或 Excel / CSV。单文件上限 20 MB，云端按 2 MB 分片上传；等待解析，查看预览与分块配置。
4. 确认构建后，在任务中心等待成功。较大文档分批向量化，进度保存到数据库，可在任务中断后继续。
5. 打开在线对话，选择知识库和对话模型，询问文件中的具体事实；查看流式回答、引用位置与原文件下载。
6. 在日志监测查看问题、回答、实际模型返回的 token 用量及耗时；服务商未返回用量时显示未知。
7. 刷新页面，确认知识库与文件仍存在。切换不同角色，确认知识库按设置可见。

图片、扫描 PDF、PDF 图片文字及增强表格解析需要另行配置 DocMind 凭证。OCR 未配置时相关任务会明确报错，不使用本地 OCR。

## 云端运行

根目录 vercel.json 声明 frontend 和 backend 两个 Services，所有 /api 路由进入后端。backend/pyproject.toml 声明 FastAPI 入口与 Celery 订阅者。构建时执行 Alembic 迁移。Services 与 Queues 采用 Vercel Beta 产品。

云端环境：DATABASE_URL（Neon 自动注入）、HUB_ENVIRONMENT=production、HUB_QUEUE_MODE=vercel、HUB_STORAGE_BACKEND=vercel_blob、HUB_DATA_DIR=/tmp/zhixu、HUB_LEASE_SECONDS=300、BLOB_STORE_ID，以及加密密钥 HUB_ENCRYPTION_KEY。私有 Blob 通过项目 OIDC 或自动注入的令牌访问。

HUB_MODEL_BOOTSTRAP 仅用于空数据库初始化，包含使用云端主密钥加密后的模型配置；后续通过管理页面修改。不要将其或任何运行时文件提交到仓库。备份模型数据时必须同时保留云端主密钥。

公开免登录和自由角色切换是本版已确认的产品行为。对话按浏览器会话隔离，知识库与模型配置由自由切换的角色共享管理。云端模型调用会产生实际服务商用量。

按发布要求，不运行新增自动化测试套件；构建与部署过程单独检查。
