## 这一版做了什么

1. 桌面 Web：工作台、知识库、文件导入、解析预览、构建流程、检索测试、在线对话、来源引用、任务、日志、模型与 OCR 配置入口。
2. 三角色：管理员、知识库管理人员、使用者；知识库按所选角色限制展示，v1.0 暂无登录。
3. 本机真实后端：FastAPI + LangChain，支持本地文档规则解析、云端 Embedding / Rerank / LLM、流式回答、引用与原文件下载、加密配置和调用日志；云端 OCR 使用阿里云 DocMind 接口，需要独立凭证。
4. 源码包含内网 Docker Compose 配置、迁移和运行说明。
5. 本次 Vercel 仅部署前端体验版，不上传本机数据库、原始文件、主密钥或已保存的 API Key，也不在公共站点调用真实模型。

## Web 体验验收

1. 打开 Vercel 页面，确认顶部显示“Web 体验版 v1.0”。
2. 以管理员创建知识库，选择示例资料或本地 Markdown，依次查看解析设置、预览确认和构建结果。Word、PDF、图片与表格的线上预览是界面演示，不代表真实解析。
3. 进入在线对话，提出资料相关问题，查看流式显示、引用原文和停止生成。
4. 查看任务中心、日志监测和模型服务；线上模型 Key 输入保持禁用，连接测试为演示。
5. 在知识库权限设置中开放使用者可见，再切换角色，检查知识库列表、导航和对话范围。
6. 刷新页面，确认当前浏览器演示记录保留；体验指引可重置演示数据。

线上 Tokens、检索结果、趋势和模型状态都是演示数据，不能据此验收模型准确率、OCR 效果、真实费用或并发性能。

## 真实后端验收

使用本机 8000 入口，页面应显示“服务已连接”。模型凭证在本机页面填写与保存，不要填写到公开说明页或聊天中。

1. 在模型服务分别配置 / 测试 LLM、Embedding、Rerank。
2. 新建知识库，上传文件，等待解析完成，核对位置后确认构建。
3. 对资料提问，检查回答、引用、原文件下载，以及日志中的实际用量与耗时。
4. 图片 / 扫描 PDF 需先启用 DocMind；内网组合部署按 [运行文档](04-后端运行与联调.md) 进行。
