# v1.2.3 导航分组与模型接入预设

## 导航

工作空间包含：工作台、知识库、在线对话、应用中心。

管理与监测包含：任务中心、日志监测、模型服务。

侧栏按分组渲染，组标题为 14px 加粗、菜单项为 13px；同组菜单间距统一，管理分组前保留组间距。移除按第四个菜单位置强行插入空白的旧样式。顶部面包屑使用同一导航定义，日志、任务、模型均显示“管理与监测”。按角色过滤后不显示空分组。

## 模型预设

| 服务商 | 配置 | 计费性质 |
|---|---|---|
| OpenRouter | `openrouter/free`，LLM | 官方免费路由，仅在免费模型间选择，有频率与每日请求限制；未配置付费模型回退。 |
| 通义百炼·北京 | `qwen-flash`，LLM | 新人限时额度，额度与有效期以百炼账号为准。 |
| 通义百炼·北京 | `text-embedding-v4`，1024 维 | 额度独立，需确认是否仍有可用额度。 |
| 通义百炼·北京 | `gte-rerank-v2`，Rerank | 额度独立，需确认是否仍有可用额度。 |

没有凭证时可以保存预设，显示“待填密钥”，不调用模型、不标记已连接。每个服务商使用各自的 API Key；AIHubMix 的 Key 不能替代 OpenRouter 或百炼的 Key。

模型页提供接入配置卡片、获取 Key 与官方规则链接。通义可用一份北京地域 Key 配置三类模型；填写凭证时需确认三项免费额度和“免费额度用完即停”。该确认属于用户在百炼的设置声明，本站不能读取账户余量，也无法代替云端计费开关。保存后逐项连接测试，只有测试成功的模型才可用于知识库和应用。

预设安装接口仅管理员可用。重复安装不重复添加；凭证加密保存、响应不返回明文，按服务商及接口地址隔离复用。

接口：`GET /api/v1/model-presets`、`POST /api/v1/model-presets/{openrouter,tongyi}/install`。

核实日期：2026-10-27。OpenRouter 公开模型目录中 `openrouter/free` 的输入与输出价格均为 0；官方目录和服务限制可能调整。

参考：[OpenRouter 免费路由](https://openrouter.ai/docs/guides/routing/routers/free-router)、[免费模型与回退规则](https://openrouter.ai/docs/guides/routing/model-variants/free)、[百炼免费额度与用完即停](https://help.aliyun.com/zh/model-studio/new-free-quota/)、[百炼模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)。
