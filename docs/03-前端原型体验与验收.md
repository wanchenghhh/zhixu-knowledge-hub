# 桌面 Web 前端原型体验与验收

日期：2026-10-26。状态：已完成前端原型，待用户确认功能与交互。

## 交付内容

React + TypeScript + Vite + Ant Design 的本地 Web 原型。原型品牌暂定为“知序”，可在后续调整。

已提供工作台、知识库列表与详情、四步导入向导、知识片段、检索测试、问答设置、权限配置、在线对话、任务中心、日志监测，以及模型/OCR 配置。

数据仅保存到当前浏览器此站点的 localStorage，不连接后端或模型服务，不接收真实 API Key。正式权限控制、密钥保存、OCR、向量索引和模型推理需在后端阶段完成。

## 推荐体验顺序

1. 以默认管理员角色进入“知识库”，查看初始资料及可见角色。
2. 点击“新建知识库”，填写名称；默认仅管理角色可见。
3. 点击“导入知识”，使用示例资料或选择本地文件。
4. 设置解析与分块参数，检查预览，确认构建。可勾选“模拟最后一个文件 OCR 超时”体验部分失败。
5. 在“任务中心”重试失败文件，或在知识库文件列表单独重试。
6. 在“检索测试”提问，查看片段、相关度及来源；不相关的问题显示空结果。
7. 在“权限与配置”开放使用者可见，然后切换角色验证列表变化。
8. 进入“在线对话”，选择知识库与对话模型，提问、停止、重新生成或查看引用。
9. 在“日志监测”查看问题、演示 Tokens、耗时和详情，按条件筛选并导出 CSV。
10. 在“模型服务”添加/编辑三类模型，切换模拟测试成功/超时；独立查看 DocMind 解析配置。

建议使用初始“员工制度与人事”知识库体验问题：“年假应该提前多久申请？”“差旅报销需要准备什么材料？”

## 原型行为与真实能力的区分

| 项目 | 当前实现 |
| --- | --- |
| 角色与可见范围 | 在浏览器中按角色过滤导航、知识库、对话历史、引用和日志；自由切换角色不验证身份 |
| 新建、设置与维护 | 可以保存、编辑、停用或删除演示资料；刷新保留结果 |
| 本地 Markdown / CSV | 可读取并预览最多 16,000 字符的文本，不执行真实解析与索引 |
| PDF、Word、图片、Excel | 校验格式和体积，展示明确标注的示例解析结果；不读取其真实二进制内容 |
| 构建与失败重试 | 使用定时状态推进与本地数据更新模拟，不调用 OCR 或 Embedding |
| 检索 | 使用固定关键词规则模拟召回和分数，不代表语义检索质量 |
| 多轮对话 | 支持会话历史、规则式追问衔接、逐字输出、停止和重新生成；答案基于演示资料摘录 |
| 模型选择 | 可配置不同服务商与模型类型，在对话区选择演示可用的 LLM |
| 引用 | 展示来源名称、位置与资料片段；真实 PDF 页码跳转尚未接入 |
| 日志用量 | 演示 Token 估算与浏览器计时；取消时用量为未知，不能当作服务商账单 |
| 模型与 OCR 测试 | 显式选择成功/超时场景，不发送真实网络请求，不保存密钥 |
| 统计趋势 | 固定演示序列并标记“演示”，不作为真实业务指标 |

本阶段按用户最新要求以桌面 Web 端为验收重点。

## 已完成的验证

`npm run build`：TypeScript 检查和生产打包通过，页面按路由拆分加载。

`npm test`：6 项自动测试通过，覆盖角色范围、跨库日志过滤、停用/失败文件不参与召回、无依据不编造引用、来源位置保留，以及不支持/超限/空文件的拒绝。

生产构建已通过桌面浏览器验证：工作台与在线对话正常显示，答案与引用匹配，未捕获控制台错误；工作台加载期间未产生外部资源请求。

浏览器实测通过的流程：

- 空名称校验 → 新建知识库 → 上传本地 Markdown → 内容预览 → 示例资料混合导入。
- 模拟部分失败 → 文件状态与任务同步 → 失败重试 → 全部就绪。
- 检索新导入文本 → 核对自定义数值与来源 → 无关问题返回无依据。
- 开放使用者可见 → 切换三角色 → 检查知识库和导航范围。
- 新增演示模型 → 模拟超时 → 再次模拟测试成功；OCR 凭证入口不接收真实密钥。
- 对话逐字输出 → 查看来源 → 停止生成保留部分回答 → 取消用量标为未知。
- 对话日志筛选 → 核对回答、引用和耗时 → 下载 CSV 并检查导出内容。
- 刷新页面后保留本地对话；新对话欢迎页回到顶部。

修复过的前端问题包括空表单校验异常、管理员专属知识库配置的可见范围保持、对话区滚动与页面间距、引用正文可读性，以及第三方组件弃用属性。
